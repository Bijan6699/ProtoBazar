# ProtoBazar

پروتوبازار — برنامه داشبورد و تحلیل فروش.

## وضعیت پروژه
این مخزن شامل کد منبع و فایل‌های لازم برای ساخت نسخه ویندوز است. فایل اجرایی نهایی هنوز باید روی ویندوز ساخته و روی یک کامپیوتر دیگر آزمایش شود؛ صرف آپلود کد در GitHub به معنی تأیید عملکرد نسخه اجرایی نیست.

## فایل‌ها
- `dashboard.py`: برنامه اصلی Streamlit
- `pricing_module.py`: ماژول قیمت‌گذاری
- `sales_analytics_module.py`: ماژول تحلیل فروش
- `logo.png`: لوگوی برنامه
- `launcher.py`: راه‌اندازی برنامه محلی و باز کردن مرورگر
- `requirements.txt`: وابستگی‌های پایتون
- `build_windows.bat`: ساخت نسخه اجرایی ویندوز
- `RUN_PROTOBAZAR.bat`: راه‌اندازی نسخه ساخته‌شده

## ساخت نسخه ویندوز
1. روی یک کامپیوتر ویندوزی Python 3.11 یا 3.12 نصب کنید. گزینه **Add Python to PATH** را فعال کنید.
2. این مخزن را دانلود و استخراج کنید یا با Git کلون کنید.
3. مطمئن شوید اینترنت برای نصب کتابخانه‌ها در دسترس است.
4. روی `build_windows.bat` دوبار کلیک کنید.
5. اگر ساخت موفق بود، پوشه `dist\ProtoBazar` ایجاد می‌شود.
6. قبل از توزیع، کل پوشه `dist\ProtoBazar` را به یک کامپیوتر ویندوزی که Python نصب ندارد منتقل و آزمایش کنید.

## توزیع برای کاربران
پوشه کامل `dist\ProtoBazar` را ZIP کنید و به کاربران بدهید. کاربران باید کل پوشه را استخراج کنند و `RUN_PROTOBAZAR.bat` را اجرا کنند. **فقط فایل `ProtoBazar.exe` به‌تنهایی کافی نیست.**

## اجرا و شبکه
برنامه از یک سرور محلی استفاده می‌کند و به‌طور پیش‌فرض در `http://127.0.0.1:8501` در همان کامپیوتر قابل دسترسی است. برای استفاده روزمره محلی، معمولاً اینترنت لازم نیست؛ اینترنت برای نصب وابستگی‌ها و ساخت اولیه لازم است.

## امنیت و داده‌ها
فایل‌های حاوی اطلاعات واقعی مشتریان، فروش، رمزها، کلیدهای API یا داده‌های محرمانه را در مخزن عمومی قرار ندهید. قبل از عمومی کردن مخزن، کد و فایل‌ها را برای اطلاعات محرمانه بازبینی کنید.

## رفع اشکال
اگر پنجره برنامه بسته شد، `ProtoBazar.exe` را از CMD اجرا کنید تا پیام خطا باقی بماند و قابل کپی باشد. خروجی خطا را همراه با نسخه ویندوز و مرحله‌ای که در آن رخ داده گزارش کنید.
